# Common Tasks

- **Adding a Feature**:
  1. Define the Model (if new data).
  2. Create the ViewModel.
  3. Create the View.
  4. Register/Navigate to the new View/ViewModel.
  
- **Images**:
  - Load bitmaps asynchronously on a background thread.
  - Bind `Bitmap` properties in ViewModel to `Image.Source` in View.
